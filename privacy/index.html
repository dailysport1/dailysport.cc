Политика конфиденциальности

Реклама · 18+

Коротко: сайт статический, форм регистрации нет, имя и контакты мы не запрашиваем. Для статистики посещений используется Яндекс Метрика.

Какие данные обрабатываются

Сайт dailysport.cc — статический, без серверной части и базы данных. Мы не запрашиваем имя, email, телефон и не создаём учётные записи.

Хостинг сайта обеспечивает GitHub Pages. При загрузке страниц инфраструктура хостинг-провайдера может фиксировать технические данные запроса — IP-адрес, тип браузера, referrer, время обращения. Эти логи находятся под контролем GitHub и обрабатываются согласно его политике конфиденциальности; у нас к ним доступа нет.

Файлы cookie

Собственные cookie сайт не устанавливает. Для анализа посещаемости на всех страницах подключён сервис веб-аналитики Яндекс Метрика (ООО «Яндекс»). Метрика использует cookie и собирает обезличенные технические данные: IP-адрес, тип устройства и браузера, источник перехода, просмотренные страницы, время на сайте, а также действия на странице (клики, прокрутка) с помощью технологии Вебвизор. Эти данные нужны только для статистики и улучшения сайта и обрабатываются согласно политике конфиденциальности Яндекса.

Отключить сбор данных можно, запретив cookie в настройках браузера или установив блокировщик Яндекс Метрики.
